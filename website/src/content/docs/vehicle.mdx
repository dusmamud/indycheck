Validates an Indian vehicle registration number: 2 state-code letters + 1–2 digit district code + 1–2 letter series + 1–4 digit number, 8–10 characters after stripping spaces and hyphens (for example `DL01AB1234` or `DL01AB123`). Spaces and hyphens between segments are accepted — plates are printed that way.

## Format — `SS NN XX(X) NNN(N)`

| Part | Meaning | Example |
| --- | --- | --- |
| `SS` | State/UT code (2 letters) | `DL` = Delhi |
| `NN` | District/RTO code (1–2 digits) | `01` |
| `XX(X)` | Series, 1–2 letters | `AB` |
| `NNNN` | Unique number (1–4 digits) | `1234` |

## Rules

| Rule | Detail |
| --- | --- |
| Length | 8–10 characters ignoring spaces/hyphens |
| Separators | Spaces and hyphens accepted even in strict mode (`DL 01 AB 1234`, `DL-01-AB-1234`) |
| State code | **Not** checked against a list of states — any 2 letters pass (for example `XX01AB1234` is valid) |
| Series letters | Any letters — there is no rule against `I` or `O` (for example `DL01IB1234` is valid) |
| Bharat (BH) series | **Not** a separate shape — `22BH1234AA` does not validate (it starts with digits) |
| Checksum | **None — format only, no public checksum** |

## Usage

```js
import { validateVehicle } from 'indycheck';

validateVehicle('DL01AB1234');
// { ok: true, code: 'VALID',
//   parsed: { registration: 'DL01AB1234', state_code: 'DL',
//             district: '01', series: 'AB', number: '1234' } }

validateVehicle('DL 01 AB 1234'); // ok: true — spaces accepted
```

```python
from indycheck import validate_vehicle

r = validate_vehicle("DL01AB1234")
print(r.parsed["state_code"])  # DL
```

```rust
use indycheck::validate_vehicle;

let r = validate_vehicle("DL01AB1234");
assert_eq!(r.parsed.unwrap()["state_code"], "DL");
```

## Examples

| Input | Result | Code |
| --- | --- | --- |
| `DL01AB1234` | ✅ Valid, Delhi | `VALID` |
| `AS01AB1234` | ✅ Valid, Assam | `VALID` |
| `DL 01 AB 1234` | ✅ Valid (spaces accepted) | `VALID` |
| `DL01AB123` | ✅ Valid (9 characters, 3-digit number) | `VALID` |
| `XX01AB1234` | ✅ Valid — the state code is not checked against a list | `VALID` |
| `DL01IB1234` | ✅ Valid — series letters may be `I` or `O` | `VALID` |
| `22BH1234AA` | ❌ Invalid — must start with 2 letters | `INVALID_FORMAT` |
| `DLAB1234` | ❌ Invalid — no district digits | `INVALID_FORMAT` |
| `DL01AB12345` | ❌ Invalid — 11 characters | `INVALID_LENGTH` |
| *(empty)* | ❌ Invalid | `EMPTY` |

## Error codes

| Code | Means |
| --- | --- |
| `EMPTY` | Nothing was passed in |
| `INVALID_LENGTH` | Not 8–10 characters (ignoring separators) |
| `INVALID_FORMAT` | Doesn't match state letters + district digits + series letters + number digits |

## Parsed output

On success, `parsed` contains:

```json
{
  "registration": "DL01AB1234",
  "state_code": "DL",
  "district": "01",
  "series": "AB",
  "number": "1234"
}
```

<Aside type="caution" title="Honest limits — format only">
  Vehicle numbers have **no public checksum**, so indycheck can only check the shape. It does not know whether the vehicle is registered, insured, or belongs to anyone — for that, use the Parivahan portal (parivahan.gov.in).
</Aside>
