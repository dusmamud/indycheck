Validates an LLP Identification Number (LLPIN): the 7-character code the Registrar of Companies (MCA) allots to every Limited Liability Partnership at incorporation. It is 3 letters (the registration series) + 4 digits (the serial).

## Rules

| Rule | Detail |
| --- | --- |
| Format | `^[A-Z]{3}[0-9]{4}$` (7 alphanumeric characters) |
| Length | Exactly 7 characters |
| Hyphen | **Not accepted.** The validator does not strip separators, so the display form `AAA-1234` is 8 characters and fails with `INVALID_LENGTH`. Pass the bare 7 characters (`AAA1234`) |
| Checksum | **None — format only, no public checksum** |

## Usage

```js
import { validateLlpin } from 'indycheck';

validateLlpin('AAA1234');
// { valid: true, code: 'VALID',
//   parsed: { llpin: 'AAA1234' } }

validateLlpin('AAA-1234'); // valid: false — INVALID_LENGTH (8 characters)
```

```python
from indycheck import validate_llpin

r = validate_llpin("AAA1234")
print(r["parsed"]["llpin"])  # AAA1234
```

```rust
use indycheck::validate_llpin;

let r = validate_llpin("AAA1234");
assert!(r.valid);
```

## Examples

| Input | Result | Code |
| --- | --- | --- |
| `AAA1234` | Valid | `VALID` |
| `AAB5678` | Valid | `VALID` |
| `aaa1234` | Valid (normalised) | `VALID` |
| `AAA-1234` | Invalid — hyphen is not stripped, so this is 8 characters | `INVALID_LENGTH` |
| `AA12345` | Invalid — 2 letters + 5 digits | `INVALID_FORMAT` |
| `AAAA1234` | Invalid — 8 characters | `INVALID_LENGTH` |
| `AAA-123` | Invalid — 7 characters, but the hyphen breaks the pattern | `INVALID_FORMAT` |
| *(empty)* | Invalid | `EMPTY` |

## Error codes

| Code | Means |
| --- | --- |
| `EMPTY` | Nothing was passed in |
| `INVALID_LENGTH` | Not 7 characters |
| `INVALID_FORMAT` | Doesn't match 3 letters + 4 digits |

## Parsed output

On success, `parsed` contains:

```json
{ "llpin": "AAA1234" }
```

Store `parsed.llpin` (`AAA1234`) in your database. There is no `formatLlpin` helper — if you want the `AAA-1234` display form, insert the hyphen yourself when rendering.

<Aside type="caution" title="Honest limits — format only">
  LLPIN has **no public checksum**, so indycheck can only check the shape. It does not confirm the LLP exists or is active — for that, search MCA master data on mca.gov.in. Companies get a [CIN](/cin/), not an LLPIN.
</Aside>
